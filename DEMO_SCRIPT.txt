--------------------------------------------------------------------------------
[ON SCREEN]:

2. Slowly hover over each category:

   - Analytics: DuckDB SQL Query, Aggregate, Join
   - Sinks: Data Output

[WHAT TO SAY]:
"You can also customize and build any pipeline manually using our wide catalog of node types. We divided them into four simple categories:

- Third, Analytics nodes: We have Aggregate nodes to calculate sums and averages, Join nodes to combine two different tables together, and a powerful SQL node that lets you write standard SQL queries.
- Finally, Output nodes: To save your clean data and download it."

🚀 Excited to share what I've been building: Reflow — a visual, real-time data pipeline orchestrator built for fast, intuitive data transformations!

Traditional data tools are often either too heavy for simple workflows or too rigid for non-engineers. I wanted to build an end-to-end platform that combines visual DAG construction with high-performance embedded analytics.

💡 What Reflow Can Do:
🤖 AI Workflow Generation: Type a prompt in plain English, and the AI drafts a fully connected DAG pipeline on the canvas.
📦 Rich Node Ecosystem: Specialized nodes for Sources (CSV, JSON, Webhooks), Shaping (Filter, Transform, Sort), Analytics (SQL, Joins, Aggregations), and Sinks.
⚡ In-Process SQL Analytics: Fast SQL queries powered by an embedded DuckDB engine with automatic schema inference.
🔄 Real-Time Streaming: Live pipeline logs and task state updates streamed over SignalR WebSockets.
☁️ Cloud Storage Persistence: Asynchronous, non-blocking artifact uploads to cloud storage.
⏱️ Automation: Built-in Cron scheduling and Webhook triggers to integrate with third-party apps.
